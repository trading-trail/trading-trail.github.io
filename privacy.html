Privacy policy

Last updated: October 4, 2026

Insider Shorts is a YouTube channel and a private software tool that its owner uses to publish videos to that channel. This policy explains what the tool accesses, how it's used, and how to revoke access.

YouTube API Services

The Insider Shorts tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What the tool accesses

The tool is used only by the channel owner, who signs in with Google to authorize it. With that permission it can:

  • Upload videos to the authorized YouTube channel and set their titles, descriptions, and tags.
  • Read basic information about the authorized channel and its videos.
  • Read YouTube Analytics reports (such as views and audience retention) for the authorized channel.

It does not access any other Google account, private messages, contacts, or payment information.

How the information is used

Channel and analytics data are used only to publish videos and to measure which videos perform best, so future videos can be improved. The data is not sold, shared with third parties, or used for advertising.

Storage and retention

Authorization tokens and analytics data are stored locally on the channel owner's computer. They are not uploaded to any other server. Stored data is deleted within 30 days after access is revoked or a deletion request is received.

Revoking access

Access can be revoked at any time from the Google security settings page.

Visitors to this website

This website doesn't use cookies, analytics, or tracking. It is hosted on GitHub Pages, which may log basic technical information such as IP addresses, as described in the GitHub Privacy Statement.

Video content

Videos are based on public SEC filings about company insiders' stock transactions. They contain no information about viewers.
